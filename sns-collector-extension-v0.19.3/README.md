# SNS 신규글 모아보기 (크롬 확장) v0.3

내가 로그인해서 쓰는 유튜브(영상·게시물), X, 인스타그램의 새 글을 **내 브라우저 안에만** 모아서 한 화면에서 봅니다. 서버·API 키·비용이 없습니다. 계정을 등록하면 **최근 7일치**를 가져오고, 이후로도 신규 글을 계속 모읍니다.

## 설치 (Chrome / Edge)
1. 이 폴더를 압축 해제해 둡니다. (삭제하면 확장이 사라지니 보관할 위치에 두세요)
2. 주소창에 `chrome://extensions` 입력 → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더 선택
4. 유튜브·X·인스타그램에 평소처럼 **로그인**해 둡니다. (로그인은 직접 하세요. 확장은 비밀번호를 다루지 않습니다.)
5. 툴바의 확장 아이콘을 누르면 대시보드가 열립니다. **추적 계정**에 보고 싶은 계정을 추가합니다.

## 추가할 수 있는 입력
| 입력 | 의미 |
|---|---|
| `@이름`, `youtube.com/@이름`, `x.com/아이디`, `instagram.com/아이디` | 그 계정 하나 |
| `youtube.com/channel/UC…`, `youtube.com/c/이름`, `youtube.com/user/이름` | 그 유튜브 채널 (`/c/`·`/user/`는 채널 ID를 찾아 변환하며 아직 실제 확인은 못 했습니다) |
| **`youtube.com`, `x.com`, `instagram.com` (사이트 메인 주소)** | 로그인된 **내 구독 피드 / 홈 타임라인 / 홈 피드** |
| 영상 주소(`watch?v=`, `youtu.be/…`) | 지원하지 않음. 채널 주소를 넣으세요 |

- 내 피드(메인 주소)는 계정을 하나씩 등록하지 않아도 구독·팔로우 중인 계정의 새 글을 모읍니다. X 홈은 화면에 선택된 탭(추천/팔로잉) 기준이라, X에서 **팔로잉** 탭을 선택해 두세요.

## 최근 7일치 가져오기
- 계정을 **처음 추가하는 순간** 그 계정의 최근 7일치를 바로 가져옵니다.
- 새 창이 열려 계정 페이지를 차례로 방문하며, 7일 전 글이 나올 때까지 스크롤해 수집한 뒤 자동으로 닫힙니다. 창이 열려 있는 동안에는 건드리지 마세요.
- 언제든 대시보드의 **최근 7일 가져오기** 버튼으로 전체 계정을 다시 가져올 수 있습니다.
- 대시보드 기본 보기도 최근 7일입니다(1/3/7/14일/전체 선택).

## 이후 신규 글이 쌓이는 방식
| 방식 | 대상 | 동작 |
|---|---|---|
| 둘러보기 | 3개 사이트 전부 | 내가 눈으로 보는 탭에서 보이는 글을 자동 수집 (자동 스크롤·클릭 없음) |
| 자동 확인 | 등록한 계정 (유튜브 게시물, X, 인스타그램) | **기본 꺼짐.** 1/3/6/12시간마다 백그라운드 탭으로 첫 화면 위주로 확인 후 닫음. 브라우저가 켜져 있을 때만 동작 |

- 계정은 최대 30개, 계정 사이에 5~10초 간격을 둡니다.

## 저장되는 것
제목·본문 앞부분(미리보기), 작성자, 링크, 썸네일 주소, 게시/수집 시각만 이 브라우저의 `chrome.storage.local`에 저장합니다. 사진·영상 파일은 저장하지 않고, 최대 5,000건이 넘으면 오래된 것부터 지웁니다. 대시보드에서 **내보내기(JSON)**, **전체 삭제**가 가능합니다.

## 알아둘 한계
- **약관**: X·인스타그램은 자동 수집을 제한할 수 있습니다. 계정 수를 적게, 자동 확인 주기를 길게 쓰세요. 계정 제재 위험은 사용자 본인에게 있습니다.
- **게시 시각**: 유튜브 게시물·영상의 "3일 전" 같은 표시는 대략적인 날짜로 환산합니다(최대 하루 정도 오차). X는 정확한 시각이 있습니다. **인스타그램 프로필 격자에는 날짜가 없어서** 7일 기준으로 거를 수 없고, 보이는 만큼(대개 최근 12개 안팎)만 가져옵니다.
- **7일치 보장 아님**: 스크롤 횟수·시간 제한(약 70초/계정)이 있어, 하루에 글을 아주 많이 올리는 계정은 7일치가 다 안 잡힐 수 있습니다.
- **검증 상태**: 유튜브(영상·게시물 선택자, 7일 전 글에서 스크롤을 멈추는 동작)는 실제 페이지로 확인했습니다. 다만 확인한 채널은 게시물이 4개뿐이라 "스크롤하면 더 불러와지는 동작"은 확인하지 못했습니다. X·인스타그램은 로그인 화면이 필요해 확인하지 못했으니, 처음 쓸 때 한 번 점검이 필요합니다.
- **화면 구조 변경**: 각 사이트의 화면 구조가 바뀌면 수집이 안 될 수 있습니다. 수정은 `youtube.js` / `x.js` / `instagram.js`의 선택자만 고치면 됩니다.
- **인스타그램 썸네일**: 주소가 만료되어 며칠 뒤 이미지가 안 보일 수 있습니다. (링크는 계속 열립니다)
- 자동 확인(백그라운드 탭)에서는 브라우저가 숨겨진 탭의 렌더링을 늦추므로, 이미지나 스크롤 로딩이 덜 되어 일부 글이 빠질 수 있습니다. 깊게 가져오려면 "최근 7일 가져오기"(보이는 창)를 쓰세요.

## 파일 구성
`manifest.json` 설정·권한 / `background.js` 저장·계정 확인 / `common.js` 공통 수집·스크롤 / `youtube.js` `x.js` `instagram.js` 사이트별 수집 / `dashboard.*` 모아보기 화면

## 수집 방식 (v0.3.3)

유튜브 영상·게시물, X, 인스타그램 모두 같은 방식입니다. 계정 페이지를 열어 화면을 읽고 7일 전 글이 나올 때까지 스크롤합니다. 유튜브 채널은 영상 탭과 게시물 탭 두 곳을 방문합니다. 유튜브 날짜는 "3일 전" 같은 상대 표기를 환산하므로 최대 약 1일 오차가 있습니다.
