SNS 모아보기

수집 켜기: 각 사이트를 직접 열어 둔 화면에서만 수집됩니다. 데이터는 이 브라우저 안에만 저장됩니다.

추적 계정

채널·프로필 주소(예: youtube.com/@이름)는 그 계정만, 사이트 메인 주소(youtube.com, x.com, instagram.com)는 로그인된 내 구독 피드·홈 타임라인·홈 피드를 가져옵니다. 계정을 추가하거나 "기간 내 글 가져오기"를 누르면, 새 창이 열려 계정 페이지를 차례로 방문하며 설정한 기간(기본 7일)의 글이 나올 때까지 스크롤해 수집한 뒤 자동으로 닫힙니다. 창이 열려 있는 동안에는 건드리지 마세요. 유튜브 채널은 영상 탭과 게시물 탭을 차례로 방문합니다. 자동 확인(기본 꺼짐)은 웹 화면(SNS 모아보기)을 보고 있을 때만 동작합니다. 화면을 보지 않는 동안은 쉬다가, 다시 볼 때 마지막 확인 후 주기가 지나 있으면 바로 한 번 확인합니다. X·인스타그램은 자동 수집이 약관상 제한될 수 있으니 계정 수를 적게, 주기를 길게 두세요.

웹 화면 연결 코드

웹 모아보기 페이지에서 로그인하면 계정에 저장된 코드가 자동으로 설정됩니다. 직접 쓰려면 이 코드를 붙여넣으면 이 확장의 데이터를 웹 화면에서 볼 수 있습니다. 코드를 아는 사람만 연결할 수 있으니 공유하지 마세요.
