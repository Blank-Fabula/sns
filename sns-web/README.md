# SNS 모아보기 (웹 화면)

유튜브·X·인스타그램에서 보고 싶은 계정의 새 글을 한 화면에 모아 보는 웹 화면입니다. 이 폴더(`sns-web`)는 서버(FastAPI, `server/main.py`)가 그대로 내려주는 정적 파일이고, 글·계정 데이터는 같은 주소의 `/api/auth`, `/api/sync`, `/api/call`, `/api/admin` 으로 주고받습니다. 설치할 것은 없고 아이디·비밀번호로 로그인만 하면 됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대와 스크립트 순서 |
| `style.css`, `bento.css` | 화면 모양(`bento.css`가 지금 쓰는 디자인) |
| `js/core.js` `bridge.js` `store.js` `list.js` `stories.js` `tracking.js` `manage.js` `account.js` | 기본 동작(서버 연결·목록·위쪽 그룹 줄·추적 계정·로그인) |
| `js/overrides.js` `ui.js` `help.js` `storyhover.js` | 위쪽 그룹 줄 동작, 휠·가로 스크롤, 도움말 |
| `js/community.js` | 커뮤니티 화면 |
| `js/hbar.js` | 카드 줄 가로 스크롤바 |
| `js/admin.js` | 관리자 대시보드(관리 탭) |
| `js/tray.js` `extras.js` | 오른쪽 아래 수집 버튼·작업 카드, 그 밖의 보조 동작 |
| `img/` | 유튜브·X·인스타 아이콘 |
| `vercel.json` `.nojekyll` | 정적 호스팅(Vercel·GitHub Pages)에 올릴 때용 |

스크립트는 `index.html`에 적힌 순서대로 불러와야 합니다(앞 파일이 만든 값을 뒤 파일이 씁니다).

## 보기

- **위쪽 그룹 줄**: 맨 위에서는 펼쳐져 있고, 아래로 내리면 접혀서 마우스를 올릴 때만 나옵니다. 그룹 아이콘을 눌러 보기 기준(그룹·유튜브·X·인스타)을 바꿉니다.
- **그룹 안의 줄**: 같은 매체 계정이 둘 이상이면 계정(`@핸들`)마다 줄을 따로 보여 줍니다.
- **가로 스크롤**: 카드 줄 위에서 마우스 휠·트랙패드, 카드를 잡고 끌기, 아래 얇은 스크롤바 모두 됩니다. 스크롤 도중 다른 탭으로 가도 새 탭 줄이 밀리지 않습니다.
- **커뮤니티**: 계정·그룹별 글과 댓글을 모아 보고, 글을 열면 그 커뮤니티 이름으로 돌아가는 버튼이 나옵니다.
- **관리**: 관리자 계정은 `관리자 대시보드`에서 서버 상태·사용자·계정 수집 현황을 봅니다.
